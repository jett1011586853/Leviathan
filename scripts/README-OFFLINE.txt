Leviathan Windows 离线安装包

安装：
1. 完整解压此 ZIP，不要只在压缩包预览窗口中运行文件。
2. 双击 install.cmd。
3. 安装完成后关闭并重新打开 PowerShell。
4. 进入任意工作目录并输入 leviathan。
5. 首次启动后输入 /model，配置使用者自己的 Base URL、模型名称和 API Key。

说明：
- 不需要安装 Bun、Git，也不需要管理员权限。
- 默认安装目录为 %LOCALAPPDATA%\Leviathan。
- 安装器会在复制前验证所有程序文件的 SHA-256。
- 此安装包不包含制作者的模型密钥、Cookie 或个人配置。
- 没有网络时可以正常使用本地功能，但模型调用仍需要能够访问使用者配置的模型服务。
- Windows 可能对未进行商业代码签名的程序显示未知发布者提示。请只使用可信来源传输且哈希一致的安装包。
