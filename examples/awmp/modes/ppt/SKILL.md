# Management Presentation Mode

Use this mode when the task requires a management-facing presentation artifact
from an existing structured report, analysis summary, or outline.

The mode must produce a `presentation.outline` artifact and a
`presentation.pptx` artifact record. It should use upstream artifact evidence
instead of inventing unsupported claims.
